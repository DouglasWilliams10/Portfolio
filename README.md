## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/seuusuario/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npm run dev
```

Acesse:

```
http://localhost:3000
```
